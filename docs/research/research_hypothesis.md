# Research Hypothesis

### Core Claim
A hierarchical, event-driven mobile agent can achieve near-real-time on-device agency by combining deterministic state transitions, ultra-low-latency System-1 semantic decisions, hardware-aware model routing, capability-specific Android execution, and event-driven verification.

### Falsification Criteria
- If model scaling beyond 10M parameters causes latency degradation exceeding the threshold of human perceptual immediacy (>100 ms) without compensatory accuracy gains.
- If event-driven verification cannot reliably detect asynchronous UI state transitions without falling back to expensive screen capture or polling loops.
