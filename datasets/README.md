# MobiMIND Datasets

- `context_benchmark_v02.json`: 25-scenario evaluation dataset covering:
  - Normal system setting toggles
  - `DoNothing` actions during camera capture and video playback
  - Ambiguous requests triggering clarification gates
  - Conflicting UI and intent states
  - Stale state detection
  - Dangerous / Adversarial requests (prompt injection and unauthorized resets)
